# Elegance - Интернет-магазин украшений

Веб-приложение для продажи украшений ручной работы, разработанное по требованиям технического задания по дисциплине HTML/CSS.

## Технологии

### Frontend
- HTML5, CSS3, JavaScript (Vanilla)
- Leaflet.js для картографии
- Chart.js для графиков и диаграмм
- Mobile First подход
- Flexbox/Grid для адаптивной верстки

### Backend (MVP)
- Node.js + Express.js
- SQLite база данных
- JWT аутентификация

## Функциональность

### Для пользователей
- 📱 Адаптивный дизайн (320px - 1920px+)
- 🛍️ Просмотр каталога украшений
- 🔍 Фильтрация и сортировка товаров
- 🗺️ Интерактивная карта магазинов
- 📊 Личный кабинет со статистикой
- 🛒 Корзина покупок
- ❤️ Добавление в избранное
- 📈 Графики покупок (Chart.js)

### Система
- 🔐 Регистрация и авторизация
- 👤 Личный кабинет с дэшбордом
- 📋 История заказов
- ⚙️ Настройки профиля
- 💳 Оформление заказов
- 📱 Геолокация пользователя

## API эндпоинты (MVP Backend)

### Аутентификация
- `POST /api/register` - регистрация пользователя
- `POST /api/login` - авторизация

### Товары (CRUD)
- `GET /api/products` - список товаров
- `GET /api/products/:id` - товар по ID
- `POST /api/products` - создать товар
- `PUT /api/products/:id` - обновить товар
- `DELETE /api/products/:id` - удалить товар

### Заказы
- `GET /api/orders` - список заказов
- `POST /api/orders` - создать заказ
- `GET /api/orders/:id` - заказ по ID
